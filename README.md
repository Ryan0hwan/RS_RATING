# 나스닥 상대강도 대시보드

S&P 500과 내 관심종목(약 680종목)의 상대강도(RS)를 매일 장 마감 후 계산해서, **웹 대시보드**를 갱신하고 **디스코드**에 상위 종목 요약과 대시보드 링크를 보냅니다.

## 계산 방식

| 항목 | 기준 |
|---|---|
| RS 점수 | IBD 방식. 3개월 수익률 40% + 6·9·12개월 수익률 각 20%를 가중합해 전체 종목 중 백분위(1~99). 99면 상위 1% |
| 1주·1개월·3개월 RS | 그 기간 수익률만으로 매긴 백분위 |
| 벤치마크 | QQQ (나스닥 100). 화면에 SPY도 함께 표시 |
| 아웃퍼폼+유동성 | 3개월 수익률이 QQQ보다 높고, 최근 3거래일 평균 거래대금 $10M 이상, 주가 $5 이상 |
| 상위 100 | 아웃퍼폼+유동성 통과 종목을 RS 순으로 100개 |
| 변동 | 직전 거래일 상위 100 대비 순위 변화. 없던 종목은 NEW |

상장 1년이 안 된 종목은 있는 기간의 수익률만으로 RS를 계산합니다.

## 대시보드 화면

| 영역 | 내용 |
|---|---|
| 머리글 | 기준일, QQQ 1·3개월, SPY 3개월 수익률 |
| 섹터 강도 | 섹터별 평균 RS(막대)와 RS 90 이상 종목 수. 누르면 그 섹터만 표시 |
| 탭 | 상위 100 / 1주 RS / 1개월 RS / 3개월 RS / 신고가 근처 / 전체 / 하위 |
| 표 | 열 제목을 누르면 정렬. 티커·종목명 검색, S&P 500·관심종목 필터 |

휴대폰에서는 종목명·섹터·변동 열을 숨겨 RS와 수익률이 먼저 보입니다.

## 실행 시각

평일 한국 시각 **06:50** (미국 장 마감 후). GitHub 특성상 5~30분 늦을 수 있고, 디스코드 알림 후 대시보드 반영까지 1~2분 더 걸립니다.

## 설치 (새 저장소, 약 15분)

### 1. 디스코드 채널·웹후크
1. 채널 목록 **채팅 채널** 옆 **+** → 새 채널 생성 (예: `상대강도`)
2. 새 채널 옆 **⚙** → **연동** → **웹후크** → **새 웹후크**
3. 생긴 봇을 펼쳐 **채널**이 새 채널인지 확인 → **웹후크 URL 복사**

### 2. GitHub 저장소
1. 오른쪽 위 **+** → **New repository** → 이름 입력 (예: `rs-dashboard`) → **Public** → **Create repository**
2. **uploading an existing file** → 아래 파일을 끌어다 놓고 **Commit changes**
   - `rs.py`, `template.html`, `watchlist.txt`, `requirements.txt`, `README.md`
   - `docs` 폴더 (폴더째 끌어다 놓으면 됨. `data` 폴더는 첫 실행 때 자동으로 생기니 안 올려도 됨)
3. **Add file → Create new file** → 이름 칸에 `.github/workflows/main.yml` 입력 → zip 안의 `main.yml` 내용 붙여넣기 → **Commit changes**

### 3. 웹후크 주소 등록
1. **Settings** → 왼쪽 **Secrets and variables** → **Actions**
2. **New repository secret** → Name: `DISCORD_WEBHOOK_URL` / Secret: 1-3에서 복사한 주소 → **Add secret**

### 4. 저장 권한 확인
1. **Settings** → 왼쪽 **Actions** → **General**
2. 맨 아래 **Workflow permissions**에서 **Read and write permissions** 선택 → **Save**

계산 결과를 저장소에 저장해야 대시보드가 갱신되기 때문에 필요합니다.

### 5. 대시보드 페이지 켜기 (GitHub Pages)
1. **Settings** → 왼쪽 **Pages**
2. **Source**: Deploy from a branch
3. **Branch**: `main` / 폴더 `/docs` → **Save**
4. 1~2분 뒤 같은 화면 위쪽에 `https://아이디.github.io/저장소이름/` 주소가 나타납니다. 이 주소가 대시보드입니다.

### 6. 첫 실행
1. **Actions** 탭 → 왼쪽 **RS Dashboard** → **Run workflow** → **Run workflow**
2. 첫 실행은 섹터·시가총액 정보를 모으느라 10~20분 걸릴 수 있습니다
3. 끝나면 디스코드에 상위 15종목 표와 대시보드 링크가 옵니다

## 알아둘 점

- **섹터·시가총액**은 한 번에 150종목씩 모아서 7일마다 갱신합니다. 첫 3~5일 동안은 일부 관심종목의 섹터·시총이 비어 있을 수 있습니다.
- **변동(NEW, ▲▼)**은 두 번째 거래일부터 표시됩니다. 첫날은 비교할 전날 기록이 없습니다.
- **대시보드는 공개 주소**입니다. 주소를 아는 사람은 누구나 볼 수 있습니다.
- 매일 결과를 저장소에 저장하므로 저장소가 계속 활동 상태로 유지되어, 60일 비활성으로 자동 실행이 멈추는 일이 없습니다.
- 시세는 야후 파이낸스 무료 데이터이고, 야후에 없는 티커는 빠집니다.

## 설정 바꾸기 (`rs.py` 맨 위)

| 항목 | 현재값 | 의미 |
|---|---|---|
| `BENCH` | QQQ | 아웃퍼폼 판정 벤치마크 |
| `OUTPERF_PERIOD` | 3m | 벤치마크와 비교할 기간 (1w, 1m, 3m, 6m, 12m) |
| `MIN_DV3` | 10000000 | 3거래일 평균 거래대금 하한($) |
| `TOP_N` | 100 | 상위 목록 개수 |
| `DISCORD_TOP` | 15 | 디스코드에 보낼 상위 종목 수 |

관심종목은 `watchlist.txt`를 고치면 됩니다. 다른 스캐너들과 목록을 같게 유지하려면 각 저장소의 파일을 모두 고쳐야 합니다.
